# Machine Learning for Public Policy (Princeton WWS 586A, Spring 2018)

Coursework from Princeton's graduate course on machine learning for public policy.

## Final project: *Understanding the Changing Economic Geography of NYC*

Which parts of New York City gained businesses between 1994 and 2014, and which fell behind? The project builds a 20-year time series of business establishments for every NYC ZIP code from Census ZIP Code Business Patterns. It then clusters the ZIP codes by their trajectories and maps the clusters.

- Notebook: [`wws586a-final-project/wws586a-final-project.ipynb`](wws586a-final-project/wws586a-final-project.ipynb)
- Report: [`wws586a-final-project/wws586a-final-project-latex/wws586a-final-project-report.pdf`](wws586a-final-project/wws586a-final-project-latex/wws586a-final-project-report.pdf)
- Methods: time series normalization, k-means (elbow method) compared with agglomerative clustering, cluster maps
